# JET Club

Class files for the JET Club programming class.

**Tools to install:** <https://tools.sadiqsalau.com>

## Get the files

1. **[Download the class files (ZIP)](https://github.com/sadiqsalau/jet-club/archive/refs/heads/main.zip)**
2. Unzip it:
   - **Windows:** right-click the ZIP › **Extract All**.
   - **Mac:** double-click the ZIP.
3. Open the folder for today.

## Day 1: your first code, and your own website

| File | What it is |
|---|---|
| `first_program.py` | Your first Python program, which we write together |
| `hello.html` | Your first web page, which we write together |
| `my-page/index.html` | Your own page to design and publish: change the parts marked ✏️ |
| `school_quiz.py` | Bonus: a quiz game to make your own |
| `guess_the_number.py` | Bonus: a guessing game |

**Python files:** open them in **Thonny** and press **F5**. No Thonny? Copy the file into [OnlineGDB's Python editor](https://www.onlinegdb.com/online_python_compiler) and press **Run**.

**Web pages:** open them in **Sublime Text** (or **Notepad++** on Windows) to change them, and double-click them to see them in your browser. After each change, save and refresh the browser.

**On a tablet or Chromebook?** You can do everything in the browser:
- **Python:** copy the file into [OnlineGDB's Python editor](https://www.onlinegdb.com/online_python_compiler) and press **Run**.
- **Web pages:** copy the file into [W3Schools Tryit](https://www.w3schools.com/html/tryit.asp?filename=tryhtml_basic), replacing what's there, and press **Run**.
- **Publishing:** in your `username.github.io` repository, use **Add file › Create new file**, name it `index.html`, and paste your finished page.

## Put your page online

1. Create a free account on [GitHub](https://github.com/signup).
2. Create a new repository named **`username.github.io`** (your username, in lowercase). Keep it **Public**.
3. **Add file › Upload files**, then upload your `index.html` from the `my-page` folder, and your photo if you added one.
4. **Settings › Pages**: publish from the **main** branch.
5. After a few minutes, your page is live at **`https://username.github.io`**.

> Your page is public: use your first name only, and nothing about where you live. Add a photo only if your parents are happy with it.

**Adding your photo:** put a picture named `photo` (`photo.jpg` or `photo.png`) in the `my-page` folder, next to `index.html`. No photo? Your emoji shows instead.
